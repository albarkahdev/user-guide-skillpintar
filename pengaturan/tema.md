# Pengaturan Tema

Atur tampilan dashboard di halaman **Appearance**.

**Alamat:** `/dashboard/settings/appearance`

## Yang bisa diatur saat ini

- **Color Scheme (warna aksen)** — pilih **Blue / Green / Purple / Orange / Red**. Berubah langsung.
- **Font Size (ukuran huruf)** — **Small / Medium / Large**.
- **Compact Mode** — merapatkan jarak & padding untuk tampilan lebih ringkas.

Perubahan tersimpan otomatis; muncul notifikasi *"Appearance settings updated successfully"*.

## Mode terang / gelap

> ⚠️ **Saat ini aplikasi terkunci pada mode Terang (Light).** Pilihan **Light / Dark / System belum tersedia** di antarmuka.
>
> Mode gelap sudah dibuat di balik layar tetapi belum siap dipakai, jadi kartu pemilihan tema sengaja disembunyikan. Fitur ini akan diaktifkan begitu semua halaman siap.
